# SciLit Scout v1.1

Локальное приложение для библиографического поиска, импорта, дедупликации, экспертного скрининга и аудита систематического обзора рекуперации кинетической энергии автотранспортных средств посредством дорожной инфраструктуры и транспортного потока.

## Возможности v1.1
- Поиск библиографических метаданных через OpenAlex, Crossref и OpenAIRE Graph (в том числе публикации с российскими аффилиациями авторов).
- Импорт CSV, XLSX, RIS и BibTeX.
- Дедупликация по DOI и нормализованному заголовку.
- Обогащение записей без перезаписи экспертных решений.
- Раздельное хранение автоматической подсказки категории и подтверждённой категории.
- Скрининг по названию/аннотации и полному тексту, история решений и аудит.
- Отдельная ручная проверка доступности полного текста.
- Экспорт реестра и отчёта в Excel и Word.
- Поддержка миграции базы данных предыдущей версии v1.0.

## Установка и запуск (Windows)
1. Распакуй весь архив в отдельную папку, например `SciLit-Scout`.
2. Для переноса прежней базы данных закрой старую программу и скопируй файл `data\\research.sqlite` в папку `data` нового проекта. Если перенос не нужен, этот шаг пропусти.
3. Дважды щёлкни `Запустить_SciLit_Scout_v1.1.1.bat`.
4. При первом запуске BAT создаст виртуальное окружение и установит зависимости. Это может занять несколько минут.
5. Не закрывай чёрное окно консоли, пока работаешь с приложением. Для остановки нажми Ctrl+C в нём.

Требуется установленный Python 3.14 и доступ к интернету при первой установке зависимостей. Если создание виртуального окружения завершится ошибкой `ensurepip`, удали папку `.venv`, восстанови/переустанови Python 3.14 с компонентом pip и запусти BAT снова.

## Ручной запуск
```bat
py -3.14 -m venv .venv
.venv\\Scripts\\python.exe -m pip install -r requirements.txt
.venv\\Scripts\\python.exe -m streamlit run app.py
```

## Методологические ограничения
- API OpenAlex и Crossref предоставляют библиографические метаданные, а не гарантированный полный текст.
- Доступность и содержание полного текста проверяет исследователь вручную.
- Автоматическая типология T1–T5 является только подсказкой и требует экспертного подтверждения.
- Сумма результатов поисковых сессий может включать повторные поиски и не равна автоматически числу уникальных записей PRISMA.
- Scopus, Web of Science, eLibrary и CyberLeninka не считаются фактически выполненными поисками, пока выгрузки из этих источников не импортированы.
- Обычное рекуперативное торможение внутри автомобиля не относится к предмету обзора, если оно не связано с дорожной инфраструктурой или транспортным потоком.

Подробная методика — в `docs_PROTOCOL.md`.


## Обновление 1.1.1

## Обновление 1.2.0 — OpenAIRE Graph

- Добавлен отдельный поиск публикаций через OpenAIRE Graph API v4.
- Поиск ограничивается публикациями, у которых указана хотя бы одна российская аффилиация автора (фильтр `authorships.countries:RU`).
- Поддерживаются тематический запрос, диапазон лет, ограничение до 2000 результатов и необязательный email для polite pool.
- Сохраняются OpenAIRE ID, DOI, авторы, аннотация, язык, ключевые слова, дата и URL доступной версии.
- Результаты поступают в общий реестр и проходят существующую дедупликацию.
- Для API используется публичный endpoint OpenAIRE Graph v4; действуют лимиты сервиса. Подробнее: https://graph.openaire.eu/docs/apis/graph-api-v4/quickstart/

Важно: фильтр российской аффилиации не означает, что публикация написана на русском языке или опубликована в российском журнале. OpenAIRE не является полной заменой РИНЦ или eLIBRARY.
