# SciLit Scout

Локальное приложение для поиска научной литературы, ведения библиографической базы, удаления дубликатов и отбора публикаций для систематического обзора.

Первая исследовательская область проекта — рекуперация энергии транспортного потока и дорожной инфраструктуры.

## Версия

1.1.0

## Назначение

- Поиск библиографических записей через OpenAlex и Crossref.
- Импорт выгрузок из научных баз данных.
- Поиск и объединение дубликатов.
- Скрининг публикаций с фиксацией решений и причин исключения.
- Проверка доступности полного текста.
- Экспорт результатов в Excel и Word.

## Хранение данных

Исследовательская база данных хранится локально на компьютере пользователя. Она не должна загружаться в этот репозиторий.
