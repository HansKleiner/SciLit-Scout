# SciLit Scout v1.1

Локальное приложение для библиографического поиска, импорта, дедупликации, экспертного скрининга и аудита систематического обзора дорожных энергетических установок.

## Главное в v1.1
- Исправлено извлечение года и даты из метаданных; исправлены регулярные выражения DOI/года.
- При повторном импорте запись обогащается отсутствующими метаданными без перезаписи решений эксперта.
- SQLite v1.0 мигрирует автоматически: новые поля и таблицы добавляются без удаления старых записей.
- Автоматическая категория хранится как подсказка `suggested_category`; подтверждённая категория назначается отдельно.
- Скрининг показывает все статусы, а поля формы изолированы по ID публикации.
- Добавлена история решений и событий аудита.
- Добавлен отдельный реестр проверки доступности полного текста.
- Финальное `include` разрешено только на этапе полного текста при подтверждённом `full_text_available=yes`.
- Экспорт Excel содержит реестр, журнал поиска, решения, аудит, обзор PRISMA и раздельные листы типов документов.
- Импорт фиксирует SHA-256 исходной выгрузки.

## Безопасное обновление с v1.0 (Windows)
1. Закрой старое приложение (в окне BAT нажми Ctrl+C).
2. Сделай копию старой папки `road_energy_review_v1` или как минимум `data\research.sqlite`.
3. Распакуй v1.1 в отдельную папку, например `road_energy_review_v1_1`. Не распаковывай поверх старой версии.
4. Скопируй папку `data` из старого проекта в новую папку v1.1. Если папки data нет — пропусти этот шаг.
5. Скопируй `exports` только если хочешь сохранить прежние экспортные файлы; это не требуется для работы базы.
6. Запусти `Запустить_Road_Energy_Review_v1.1.bat`.
7. При первом запуске v1.1 расширит схему SQLite. Старую папку оставь как резервную копию.

**Важно:** не копируй SQLite, пока старый Streamlit ещё работает. Для дополнительной страховки сохрани отдельную копию `research.sqlite`.

## Установка вручную
Требуется Python 3.10+; для подготовленного BAT-файла настроен Python 3.14:
```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

## Запуск
Дважды щёлкни `Запустить_SciLit Scout_v1.1.bat`. Окно консоли оставляй открытым. Для остановки нажми Ctrl+C в этом окне.

## Методологические ограничения
- API возвращают метаданные, а не подтверждённый полный текст.
- Полный текст проверяет исследователь вручную.
- Автоматическая типология T1–T5 — только подсказка.
- PRISMA overview показывает контрольные значения локальной базы. Сумма найденного по сессиям может включать повторные поиски и не равна автоматически числу уникальных записей, идентифицированных по PRISMA.
- Scopus/WoS/eLibrary/CyberLeninka не считаются выполненными поисками, пока фактические выгрузки из этих источников не импортированы.
